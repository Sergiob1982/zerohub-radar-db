# zerohub-radar-db

Base de radares (fijos + tramos) para la app **ZeroHub**.
Actualizacion **firmada** (RSA-3072 / SHA-256), generada automaticamente desde fuentes publicas.

- `manifest.json` - version, fecha, tamano, sha256, URL y firma (base64)
- `radares_es.bin` - base de radares (formato ZRAD)
- `radares_es.bin.sig` - firma RSA-SHA256 del .bin

Datos (c) OpenStreetMap contributors (ODbL) + DGT.
